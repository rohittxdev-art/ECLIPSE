# ECLIPSE

A privacy-first personal digital vault for web, desktop, and mobile.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- Rust security core (planned; cryptographic operations will use audited libraries)
- Supabase (dedicated ECLIPSE project required)
- Tauri for desktop packaging (planned)

## Security status
This repository currently contains the UI foundation only. Do not store real passwords, private documents, or other sensitive data until client-side encryption, key management, authorization, recovery, and security review are implemented.

## Development
```bash
npm install
npm run dev
```
